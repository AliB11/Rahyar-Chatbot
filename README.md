# راهیار — دستیار هوشمند دانش بانکی

راهیار یک وب‌اپ فارسی و راست‌چین برای پرسش‌وپاسخ روی اسناد و منابع داخلی سازمان است. رابط کاربری با Next.js، داده‌ها با PostgreSQL و Drizzle ORM، و بازیابی اسناد با قطعه‌بندی هم‌پوشان و رتبه‌بندی BM25 فارسی پیاده‌سازی شده است. در صورت پیکربندی یک سرویس سازگار با OpenAI، embedding و تولید پاسخ مستند نیز فعال می‌شود؛ بدون آن، سامانه با بازیابی واژگانی فارسی و پاسخ مبتنی بر گزیدهٔ اسناد کار می‌کند.

## شروع سریع

1. مقدار `DATABASE_URL` را برای PostgreSQL محیط تنظیم کنید (فایل `.env.example` را ببینید).
2. وابستگی‌ها را نصب و جداول را اعمال کنید:

   ```bash
   npm install
   npx drizzle-kit push
   npm run dev
   ```

   فایل پیکربندی drizzle از `DATABASE_URL` محیطی استفاده می‌کند؛ فرمان‌های کنترل کیفیت (`typegen`/`typecheck`/`build`) بدون این متغیر هم اجرا می‌شوند.

3. در نخستین بازدید از برنامه، فرم «راه‌اندازی اولیه» را تکمیل کنید. اولین حساب به‌صورت اتمیک مدیر سیستم می‌شود؛ پس از ساخت مدیر، راه‌اندازی عمومی بسته است.
4. مدیر از بخش «کاربران و دسترسی» حساب‌ها را می‌سازد و هر حساب را به یک واحد سازمانی نسبت می‌دهد.

هیچ حساب یا گذرواژهٔ پیش‌فرضی در برنامه وجود ندارد. گذرواژه‌ها با scrypt و نشست‌ها به شکل توکن تصادفیِ غیرقابل‌خواندن در پایگاه‌داده نگهداری می‌شوند.

## پیکربندی محیطی

متغیرهای زیر را در محیط سرور تنظیم کنید؛ کلیدها را در bundle مرورگر قرار ندهید:

| متغیر | کاربرد |
| --- | --- |
| `DATABASE_URL` | اتصال PostgreSQL اصلی برنامه |
| `APP_ENCRYPTION_KEY` | کلید پایدار و تصادفی برای رمزنگاری نشانی‌ها، توکن API و اعتبارنامهٔ منابع؛ در استقرار واقعی تنظیم شود |
| `OPENAI_API_KEY` | اختیاری؛ فعال‌سازی embedding و تولید پاسخ با سرویس سازگار با OpenAI |
| `OPENAI_BASE_URL` | اختیاری؛ نشانی پایهٔ سرویس سازگار با OpenAI، پیش‌فرض `https://api.openai.com/v1` |
| `OPENAI_CHAT_MODEL` | اختیاری؛ پیش‌فرض `gpt-4o-mini` |
| `OPENAI_EMBEDDING_MODEL` | اختیاری؛ پیش‌فرض `text-embedding-3-small` |

اگر `APP_ENCRYPTION_KEY` تنظیم نشده باشد، برنامه برای رمزنگاری منابع از `DATABASE_URL` به‌عنوان کلید مشتق‌شده استفاده می‌کند؛ در استقرار پایدار حتماً کلید مستقل تنظیم کنید و آن را در زمان تعویض/بازیابی اطلاعات حفظ کنید. با تغییر این کلید، تنظیمات منابع ذخیره‌شده قابل رمزگشایی نخواهند بود.

**ملاحظات داده:** در صورت فعال‌کردن `OPENAI_API_KEY`، پرسش و قطعه‌های بازیابی‌شده برای تولید پاسخ به سرویس مدل انتخاب‌شده ارسال می‌شوند. پیش از فعال‌سازی برای داده‌های بانکی، سیاست امنیت و محل پردازش دادهٔ سازمان را بررسی کنید. بدون کلید مدل، پردازش و بازیابی در خود برنامه انجام می‌شود.

## بارگذاری سند

مدیر سامانه می‌تواند سند را برای دامنهٔ «عمومی» یا یک واحد مشخص بارگذاری کند. متن از فایل استخراج می‌شود؛ فایل خام نگهداری نمی‌شود. فرمت‌ها:

- PDF متنی
- Word: `DOCX`
- Excel: `XLSX` و `XLSM`
- `CSV`، `TSV`، `JSON`
- `TXT`، `MD`، `HTML`، `XML`، `YAML`، `LOG`، `INI` و `SQL`

محدودیت حجم فایل ۲۰ مگابایت و سقف متن استخراج‌شده ۱٫۵ میلیون نویسه است. فایل‌های PDF اسکن‌شده به OCR نیاز دارند و بدون لایهٔ متنی، محتوای قابل بازیابی تولید نمی‌کنند.

## اتصال منابع سازمانی

بخش «منابع داده» در اختیار مدیر است و سه نوع اتصال دارد:

- **صفحه داخلی:** خواندن متن صفحهٔ HTTP/HTTPS و تبدیل HTML به متن.
- **REST API:** درخواست `GET` و دریافت JSON یا متن؛ امکان توکن `Bearer` وجود دارد.
- **PostgreSQL:** اجرای یک پرس‌وجوی `SELECT`/`WITH` در تراکنش فقط‌خواندنی، با محدودیت زمانی و حداکثر ۱۰۰۰ ردیف خروجی.

نشانی‌ها و اعتبارنامهٔ منابع در پایگاه‌داده رمزنگاری می‌شوند. هنگام ساخت اتصال، دامنهٔ «عمومی» یا واحد مقصد را تعیین و سپس منبع را دستی همگام‌سازی کنید. دسترسی خروجی شبکهٔ سرور به مقصدهای داخلی باید مطابق سیاست شبکهٔ سازمان محدود شود.

## نقش‌ها و محدودهٔ دسترسی

- مدیر اولیه فقط با setup یک‌باره ساخته می‌شود.
- مدیر سیستم می‌تواند سند بارگذاری کند، منابع را متصل/همگام‌سازی کند و کاربران و نقش‌ها را مدیریت کند.
- کاربر عادی فقط سندها و منابع «عمومی» و موارد متعلق به واحد خود را می‌بیند و در بازیابی RAG استفاده می‌کند.
- APIها نقش و دسترسی را در سمت سرور کنترل می‌کنند؛ رابط کاربری صرفاً بازتاب این محدودیت‌هاست.
- نشست‌ها با cookieهای `HttpOnly`، `SameSite=Lax` و در production با `Secure` نگهداری می‌شوند. تغییرهای مدیریتی اصلی در `audit_logs` ثبت می‌شوند.
- مسیرهای «ورود» و «راه‌اندازی» محدودکننده نرخ درون‌حافظه‌ای دارند: پس از ۸ تلاش ناموفق در بازه ۱۰ دقیقه، پاسخ `429` برمی‌گردد؛ تلاش موفق این شمارنده را صفر می‌کند. برای استقرار چند-نمونه‌ای این شمارنده را با ذخیره‌ساز مشترک (مثل Redis) جایگزین کنید.
- هدرهای امنیتی `X-Content-Type-Options`، `X-Frame-Options`، `Referrer-Policy` و `Permissions-Policy` در `next.config.ts` برای همه مسیرها تعریف شده‌اند.

## کنترل کیفیت

```bash
npx next typegen
npm exec tsc -- --noEmit --pretty false
npm run build
```

مسیر `/api/health` اتصال PostgreSQL برنامه را بررسی می‌کند.
